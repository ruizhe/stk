# Launcher icons

The normal-mode browser SVGs are sourced from the MIT-licensed
[`browser-logos`](https://github.com/alrra/browser-logos) project. Browser names and logos are
trademarks of their respective owners. See `LICENSE.browser-logos.txt` for the upstream license.

The `*-private.svg` files are STK-provided compact privacy-mode variants. They use the private
browsing symbol appropriate to the browser engine and each browser's brand palette, so private
mode remains distinguishable at launcher-menu sizes.
